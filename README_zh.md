## 项目简介
**ABAP 编程练习平台**是一个基于 SAP GUI 的交互式代码练习系统。本平台允许开发者直接在 SAP 环境中学习、练习和测试 ABAP 代码。

## 系统要求
* **SAP NetWeaver / ABAP Platform**: 版本 **>= 7.54**。

## 核心功能

* **练习题维护 (`ZRPEX001`)**：为导师提供的控制台，用于创建、编辑、加载、保存和删除练习题。支持分屏编辑器，可分别维护 HTML 格式的题目描述、提供给学习者的初始 ABAP 代码模板，以及隐藏的 ABAP 单元测试逻辑。
* **交互式编程环境 (`ZRPEXERCISE002`)**：核心的练习平台。用户可以通过 ALV 列表浏览所有练习题。选择题目后，左侧将显示 HTML 格式的题目要求，右侧提供 ABAP 编辑器供用户编写解答。
* **代码动态评测**：当用户点击“运行测试”时，平台会将用户提交的代码与隐藏的测试代码合并，并使用 `GENERATE SUBROUTINE POOL` 进行动态执行。测试结果（通过/失败）会直接注入到 HTML 视图中，提供即时的可视化反馈。
* **解法分享 (`ZRPEXERCISE003`)**：一个协作学习空间。这里展示了所有已成功通过测试的提交记录，用户可以互相查看他人的具体代码，学习同一问题的不同解决思路。
* **数据备份与恢复 (`ZRPEXERCISE_DOWNLOAD` / `ZRPEXERCISE_UPLOAD`)**：内置的数据迁移工具，支持将练习题元数据和用户提交记录下载为本地 XML 文件，或将其从本地上传至数据库。
* **单元测试工具类 (`ZCL_EXERCISE_UNIT_TEST`)**：专用的测试类，用于在动态执行期间记录断言（`assert_equals`）并追踪测试结果。

## 数据库架构
平台底层主要依赖两张透明表：
* `ZTEX_DESC`：存储练习题的元数据，包括 HTML 描述、初始代码和单元测试代码。
* `ZTEX_SUBMISSION`：记录用户的提交状态，包含用户 ID、提交的 ABAP 代码以及首次成功通过测试的时间戳。
